# Christopher Esterguard

Audio engineer in Hamburg. 14 years in voice recording, dialogue editing and production sound for radio, film, TV and podcasts.

I build small, local-first tools that make audio work faster:

- **[audio-prep-qc](https://github.com/Sleightly2015/audio-prep-qc)**: checks voice and podcast files for loudness, true peak, noise floor, clipping and silence, then writes a one-page report. Runs entirely on your machine.
- **[presenter-cards](https://github.com/Sleightly2015/presenter-cards)**: turns a Markdown outline into printable A6 cue cards for talks and workshops.
